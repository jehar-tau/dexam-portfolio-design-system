Two-column workspace shell — a warm narrow sidebar (pair with `SidebarItem`) beside a white content column. The structural pattern behind the portfolio's document-like pages.

```jsx
<SidebarLayout sidebar={<><SidebarItem label="Work" active/><SidebarItem label="About"/></>}>
  <DocumentPageBlock title="Onboarding Redesign">...</DocumentPageBlock>
</SidebarLayout>
```
